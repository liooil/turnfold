# Contributing

Issues and focused pull requests are welcome.

Before submitting a change:

```sh
bun install
bun run typecheck
bun test
bun run build
```

Use two-space indentation in TypeScript, JavaScript, HTML, CSS, and YAML. Keep changes focused and include tests for repository, transfer-format, provider, or rendering behavior where practical.

Do not include credentials, private conversation exports, generated databases, or deployment-specific identity headers in fixtures.
