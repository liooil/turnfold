Turnfold 是本地优先的 AI 对话仓库。编辑与重新生成不会覆盖过去，而会形成可导航的分支式消息历史。 Turnfold is a local-first repository for AI conversations. Edits and regenerations preserve the past as navigable branches instead of overwriting it.

核心特性What matters

为可塑的对话而设计Built for conversations that evolve

01

本地优先Local first

IndexedDB 保存消息、引用、草稿和待同步操作；无需服务器返回即可渲染。IndexedDB holds messages, refs, drafts, and pending operations, ready to render without a server round trip.

02

保留分支Preserved branches

消息是不可变对象。编辑、重试和回复旧消息都会保留来源与替代路径。Messages are immutable objects. Edits, retries, and replies to older messages retain their origin and alternatives.

03

模型自由Model freedom

连接 OpenAI、Anthropic、Google、Ollama、LM Studio、llama.cpp、vLLM 及兼容端点。Connect OpenAI, Anthropic, Google, Ollama, LM Studio, llama.cpp, vLLM, and compatible endpoints.

04

数据可迁移Portable data

导入导出原生归档，以及 Codex CLI、Claude Code 与 OMP JSONL 会话。Import and export native archives plus Codex CLI, Claude Code, and OMP JSONL sessions.

一分钟自托管Self-host in a minute

运行自己的 TurnfoldRun your own Turnfold

自托管 Web App 需要 Docker Compose；模型请求仍由浏览器直接发送到其可访问的 Ollama、LM Studio 或其他模型服务。Self-hosting the web app requires Docker Compose. Model requests still go directly from the browser to a reachable Ollama, LM Studio, or other model endpoint.

git clone https://github.com/liooil/turnfold.git
cd turnfold
docker compose up --build -d
